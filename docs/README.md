## 4. 设计基线（贯穿所有文档）

1. **一个应用，多个 LearningSpace**：数学和 408 只是两条数据，不是代码分支。学科差异通过「AI 分析配置（ai_profile）+ Prompt 模板 + Space/Subject 附加指令」来表达。
2. **Archive 是事实来源**：原始文件只增不改；AI 结果永远可以追溯到题目、文件和页码。
3. **AI 结果有版本、要确认、可纠正**：每次分析（包括用户手工修正）都生成新版本，从不覆盖。只有用户确认过的结果才算「可信数据」，将来的复习和学习画像只使用这部分数据。
4. **AI 上下文按作用域组装**：不向任何请求发送整个知识库。
5. **模块化单体**：Spring Boot 单体，按业务域分包；不引入微服务、Redis、MQ、向量库或 Agent 框架。
6. **垂直切片开发**：每个里程碑都产出一个端到端可用的功能。
